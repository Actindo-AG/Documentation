# Attribute groups

Attributes can be flexible organized within groups and sub-groups.   
Within a product, users can seamlessly scroll through sub-groups. Clicking is required to navigate between top-level groups.   
For products that do not contain all attributes, groups without attributes will not be displayed.   
The following keys steps and considerations are involved when creating attribute groups and assigning attributes to them.

> [Info] By default, the *Basic Data* attribute group has been created.


## Create an attribute group

*PIM > Settings > Tab ATTRIBUTE GROUPS*

1. Click the [Edit] button to the right of the *Attribute groups* section in the left column.   
    
2. Click the [Add] button in the bottom right corner to add a new top level group or select the top-level group to which you want to add a sub-group and click the [Add] button in the bottom right corner.
    > [Info] Only one sub-group level is allowed.

3. Click the plus sign in the attribute group column.
   
4. Enter a name for the attribute group and, if desired, a key.

5. Click first the [SAVE] button in the *Add element* window and then the [SAVE] button in the upper right corner of the *Edit attribute groups* view.

    > [Info] Groups and sub-groups can be reordered by clicking the three lines icon and using drag and drop


## Assign attributes to an attribute group

*PIM > Settings > Tab ATTRIBUTE GROUPS*

1. Select the attribute group or sub-group to which you want to add an attribute and click the [Add] button in the bottom right corner to display a list of all attributes.

    > [Info] An attribute can only exist in one group at a time. Adding an attribute which is already assigned to another group will remove it from its previous location without warning. To prevent unintended reassignment, enable the *Unassigned Attributes* toggle to display only unassigned attributes.

2. Select the checkboxes of the attributes you want to add to the selected attribute group. 
   
    > [Info] Multiple attributes can be selected and added to a group simultaneously.

3. Click the [ADD] button in the editing toolbar.

    > [Info] Changes to group assignments are saved automatically. 



## Sample scenario &ndash; Create attribute groups and assign attributes to them

You have already created the attributes *Collar size*, *Sleeve length*, *Storage* and *Screen size*. 
These attributes must be assigned to a certain attribute group. The predefined *Basic Data* attribute group already contains the *Sizes* sub-group to which you will assign the *Collar size* and *Sleeve length* attributes in the next step. However, it is necessary to create attribute groups for the *Storage* and *Screen size* attributes in the following.

1. Create Storage sub-group
2. Create Screen sub-group 
3. Change order of sub-groups
4. Assign attributes to the sub-groups
